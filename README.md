# Sound-UI-Authoring

## Introduction 
Hi Everyone! Welcome to the Sound-UI-Authoring repository. The goal of this project is to give deaf and hard of hearing folks the opportunity to author the enviornment that they are in. 

A user can, for example, ask for all of the sounds of birds to show up as waves and that waves be a height with respect to how loud the chriping of the birds are. 

With this tool, we hope that users are able to better understand their world audio wise and gather information that was hard to gather before.


## System Overview 
- Our system continously takes in sound information and saves the sound information into a file 
- When a user gives the system feeedback, we take in the audio from a period of time
- We then, will use the feedback and audio to generate 2D UI components
- We will then test these 2D UI componenets within a test application to see if they work 
- We will then intergrate the 2D UI componenets into the application

## Installation 
- make sure to have `2022.3.52f1` installed for unity
